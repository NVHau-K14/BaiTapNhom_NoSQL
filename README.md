# BaiTapNhom_NoSQL
XÂY DỰNG ỨNG DỤNG QUẢN LÝ SINH VIÊN VỚI MONGODB
Cách mở và chạy web "Quản lý sinh viên với MongoDB"
1. Tải code về và mở file solution (web_qlsinhvien.sln)
2. Tải gói MongoDB.Driver
Cơ sở dữ liệu MongoDB
1. Kiểm tra file data_seed.js đã tồn tại trong project chưa
2. Thêm cơ sở dữ liệu bằng cách mở terminal tại thư mục chứa tệp và gõ: ":mongosh "mongodb://localhost:27017" data_seed.js"
hoặc mở powershell trong MongoDB và copy toàn bộ câu lệnh trong file data_seed.js rồi chạy
